## About

This repository contains the public-facing privacy policy for the **Hafiz Al-Husna** app. The page explains account information, Google Sign-In, Firebase-related data handling, deletion requests, security, and contact details in a clear mobile-friendly layout.

## Features

- Single-file static site with no build step
- Responsive typography and content container
- Branded application logo
- Clearly separated privacy sections
- Suitable for GitHub Pages or any static host

## View Locally

```powershell
git clone https://github.com/tasnimrimi/Hafiz-Al-Husna-Privacy-Policy.git
cd Hafiz-Al-Husna-Privacy-Policy
start index.html
```

Alternatively, open `index.html` directly in a browser.

## Maintenance Note

The published policy should always match the app’s real data collection, authentication, storage, deletion, and third-party service behavior. Update both the effective date and policy text whenever those practices change.
